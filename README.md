# NTI MEAN Stack Web Development Summer Training

This repository contains all the tasks, assignments, mini-projects, and the final project completed during the **National Telecommunication Institute (NTI) Summer Training – MEAN Stack Web Development**.

The training focuses on building practical full-stack web development skills using the **MEAN Stack** while covering essential topics for freelance software development, including web security, SEO, UI/UX, project management, and client communication.

## Training Information

* **Program:** MEAN Stack Web Development
* **Provider:** National Telecommunication Institute (NTI)
* **Duration:** 90 Hours
